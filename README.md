# dev-notes

> My personal notes and challenge solutions on my path to becoming a full stack developer (JavaScript, MySQL, React, Node).

Apuntes personales de mi camino para convertirme en desarrollador full stack.

## Estructura

| Carpeta | Contenido |
| --- | --- |
| [`javascript/`](javascript/README.md) | Un archivo por tema del curso de JavaScript |
| [`mysql/`](mysql/README.md) | Un archivo por tema del curso de MySQL |
| [`retos/`](retos/README.md) | Soluciones de CodeChef y midu.dev |
| [`TEMPLATE.md`](TEMPLATE.md) | Plantilla para temas nuevos |

## Cómo uso estos apuntes

1. **Mientras veo el curso:** anoto solo lo que me costó entender o lo que creo que voy a olvidar, con mis palabras.
2. **Al terminar una sección:** completo el ejemplo mínimo y marco las preguntas que ya sé responder.
3. **Al empezar cada sesión:** repaso 10 minutos los apuntes del día anterior.
4. **Cada reto resuelto** se guarda en `retos/` con la idea de la solución y lo que aprendí.

## Rutina de Git (al final de cada día)

```bash
git add .
git commit -m "notes: arrays (map, filter, reduce)"
git push
```

Prefijos de commit que uso:

- `notes:` apuntes de un tema
- `challenge:` solución de un reto
- `fix:` corrección de apuntes anteriores
